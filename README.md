# Civitai local index

This repository contains the media-free, provenance-aware Civitai image/tag indexer in [`civitai-indexer/`](civitai-indexer/).

It stores structured metadata and verified formal image→tag relations only—never image or video bytes—and makes local Boolean tag querying, source coverage accounting, cursor checkpoints, and incremental synchronization reproducible.

Start with [`civitai-indexer/README.md`](civitai-indexer/README.md).
